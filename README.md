# TMS-Nav
A python repository for comparing TMS target localization method efficacies

## data / privacy
patient mris and anything derived from them (meshes, renders) are gitignored and
never committed. they live under saves/ and viewer/src/data/ locally and get
regenerated by the pipeline, so a fresh clone starts empty of patient data.

## usage
feed an mri (or a folder of them) through the pipeline. each one gets a front and
a side png preview under saves/previews/, plus the meshes and markers the viewer
needs under viewer/src/data/<subject>/:

    python run_pipeline.py [mri_or_folder]

defaults to the saves/ folder.

## viewer
interactive 3d view of the head, brain, targets, eeg landmarks and a coil:

    cd viewer
    npm install
    npm run dev

## other
    python analysis/sample_size.py    # aim 1 sample size sweep
